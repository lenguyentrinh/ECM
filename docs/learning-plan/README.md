# Lộ trình học lên Senior (dùng repo English Center)

Mục tiêu: từ 1.5–2 năm kinh nghiệm, hiểu sâu để **review, thiết kế và chịu trách nhiệm** cho code (kể cả code AI sinh ra).

## Cấu trúc folder

| File | Nội dung | Thời gian |
|---|---|---|
| [00-ai-workflow.md](00-ai-workflow.md) | Làm việc với AI: context file, skills, giao việc, review | Tuần 1–2 |
| [01-foundations.md](01-foundations.md) | Git, HTTP, SQL, Docker/CI, setup project từ 0 | Tuần 3–5 |
| [02-backend.md](02-backend.md) | Java, Spring, JPA, Security, Test | Tuần 6–13 |
| [03-frontend.md](03-frontend.md) | JS/TS, React, Redux, kiến trúc, hiệu năng | Tuần 14–20 |
| [04-senior-mindset.md](04-senior-mindset.md) | System design, ADR, vận hành, review, debug | Tuần 21–26 |
| [progress.md](progress.md) | Checklist tiến độ + nhật ký học | Liên tục |

## Vòng học mỗi tuần (8–10 giờ)

1. **2h** đọc lý thuyết / docs chính thức
2. **3h** đọc code liên quan trong repo, vẽ lại luồng chạy
3. **3h** tự viết lại, **không dùng AI**
4. **1h** ghi note: "vì sao chọn cách này", lỗi đã gặp (vào `progress.md`)

## Quy tắc

- Mỗi tháng có 1 tuần "không AI" cho một tính năng nhỏ.
- Mỗi chủ đề phải trả lời được phần **Câu tự kiểm tra**. Chưa trả lời được bằng lời của mình = chưa xong.
- Học xong chủ đề nào thì viết 1 đoạn giải thích như đang dạy người khác.
